Описание:
Django_Work - представляет собой проект, в котором реализован функционал Django при работе со страницами.
Установка:
1. Клонируйте репозиторий:
git@github.com:pannikolaserg-prog/Django_Work.git
Использование:
1. Откройте проект в вашем PyCharm.
2. Приложение catalog обеспечивает отображение двух страниц с применением стилизации Bootstrap.
3. Для отображения двух страниц home и contacts применены контроллеры.
4. На странице contacts реализована форма обратной связи.
Документация:
Для получения дополнительной информации обратитесь к документации README.txt.
